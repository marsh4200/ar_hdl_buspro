# Brand assets

HDL logo prepared to the home-assistant/brands spec (transparent background):

- `icon.png` 256x256 / `icon@2x.png` 512x512 - square, centered
- `logo.png` 128px tall / `logo@2x.png` 256px tall - original aspect

Home Assistant only serves brand images from brands.home-assistant.io, so to
get the logo showing in the HA UI, submit these four files as a PR to
https://github.com/home-assistant/brands under
`custom_integrations/ar_hdl_buspro/`. Until merged, HA shows the default puzzle icon.
